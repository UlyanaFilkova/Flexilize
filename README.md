# Context Translator — расширение Chrome и Firefox

Расширение реагирует на выделение текста на веб-странице, показывает перевод на русский язык, транскрипцию и кнопку озвучки. Каждое выделение вместе с предложением и переводом сразу сохраняется в локальном хранилище расширения.

Проект написан на TypeScript и собирается через [Extension.js](https://extension.js.org/). Из одной кодовой базы создаются Chrome Manifest V3 и Firefox Manifest V2 сборки. Promise-based API `browser.*` унифицирован официальным `webextension-polyfill` Mozilla.

## Разработка

Требуется Node.js 22.12 или новее. Рекомендуемая версия записана в `.nvmrc`.
Команды `npm run ...` автоматически используют эту версию из установленного `nvm`, даже если текущая версия Node.js в терминале старее.

```bash
nvm use
npm install
npm run dev:chrome
```

Для запуска в отдельном профиле Firefox:

```bash
npm run dev:firefox
```

Проверка типов и production-сборки:

```bash
npm run typecheck
npm run build:chrome
npm run build:firefox
```

Результаты появляются в `dist/chrome` и `dist/firefox`.

## Установка сборки в Chrome

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `dist/chrome`.

## Упаковка для магазинов

```bash
npm run zip:chrome
npm run zip:firefox
```

Extension.js создаст ZIP-архивы внутри соответствующих папок `dist`. Firefox-сборка проходит проверку `addons-linter`, требует Firefox 142+ и использует WebExtension API, совместимые с Firefox для компьютера и Firefox для Android. Тестирование мобильного интерфейса на реальном устройстве остаётся обязательным перед публикацией.

После установки выделите слово или фразу на обычной веб-странице. Модальное окно закрывается кликом вне него, при прокрутке или потере фокуса вкладки.

## Сохранение и экспорт

Записи сохраняются немедленно через `storage.local` и остаются после перезапуска браузера. Нажмите значок расширения, чтобы просмотреть список и скачать его как JSON или CSV. Это надёжнее автоматического скачивания нового файла при каждом выделении: браузеры не разрешают веб-расширению без постоянного пользовательского разрешения произвольно дописывать данные в файл на диске.

Хранится не более 5000 последних записей. Список можно очистить из popup-окна.

## Используемые возможности

- Web Speech API — озвучка наиболее естественным доступным голосом нужного языка;
- MyMemory API — контекстный перевод с английского на русский: выделенное слово переводится внутри предложения, варианты очищаются от нерелевантных данных, изменённые формы дополнительно ищутся по базовой форме;
- Datamuse API — основная IPA-транскрипция английских слов и фраз (до 30 слов); ответы ARPAbet автоматически преобразуются в IPA;
- Free Dictionary API — резервный источник IPA-транскрипции;
- English Wiktionary — словарные варианты перевода по частям речи; порядок вариантов уточняется по контексту;
- стандартные WebExtension API `runtime` и `storage` через Promise-based `browser.*`.

Для перевода и словарной транскрипции требуется интернет. На системных страницах вида `chrome://…` и `about:…` content script не запускается — это ограничение браузеров.

Словарные данные English Wiktionary доступны по лицензиям проекта Wikimedia; источник: https://en.wiktionary.org/.
