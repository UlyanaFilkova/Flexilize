# Context Translator — кроссбраузерное расширение (Chrome/Edge + Firefox)

Мгновенный перевод, прослушивание и сохранение фрагментов текста на английском языке.

Расширение реагирует на выделение английского текста на веб-странице, показывает варианты перевода на русский, отдельный контекстный перевод всего предложения или абзаца, транскрипцию и озвучку. Каждое выделеное слово вместе с предложением и переводом сразу сохраняется в локальном хранилище расширения, и в любой момент можно скачать все переводы в JSON или другом формате.

## Для чего это нужно:
1) Когда вы читаете текст на иностранном языке, у вас нет времени заносить все слова в словарь, тем более записывая не только слово, но и контекст, в котором оно было использовано. Вы хотите быстро узнать перевод незнакомого слова и двигаться дальше.

2) Расширение позволяет автоматически сохранять все необходимые данные в файл, который позже вы можете скормить нейронке, и она сгенерирует вам словарь.

3) Лимит сохраненных переводов равен 5000, и если лимит достигнут, появится уведомление, которое предложит вам скачать уже сохраненные переводы, а затем очистить хранилище и начать сохранять переводы заново. 

4) Если вы хотите вручную управлять сохранением переводов, эта опция доступна в настройках расширения. По умолчанию сохраняются все выделенные слова, но их также можно вручную редактировать и удалять.

## Разработка

Требуется Node.js 22.12+.

```bash
npx extension dev --browser=chrome     # запуск Chrome с горячей перезагрузкой
npx extension dev --browser=firefox    # запуск Firefox
```

## Сборка

```bash
npx extension build --zip              # готовые архивы для обоих браузеров
npx extension build --browser=firefox --zip
```

Результат сборки:

- `dist/chrome/` и `dist/firefox/` — распакованные сборки;
- `dist/context-translator-1.1.0-chrome.zip` и `dist/context-translator-1.1.0-firefox.zip` — архивы для установки и публикации.

## Установка

Chrome / Edge:

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `dist/chrome`.

Firefox:

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение** и выберите `dist/firefox/manifest.json`.

После установки выделите английское слово или фразу на любой веб-странице. Появится модальное окно с переводом, и перевод сразу сохранится в локальное хранилище расширения.

Модальное окно закрывается кликом вне него, при прокрутке или потере фокуса вкладки.

## Сохранение и экспорт

Записи сохраняются немедленно через `storage.local` и остаются после перезапуска браузера. Нажмите значок расширения, чтобы просмотреть список и скачать его как JSON или CSV. Это надёжнее автоматического скачивания нового файла при каждом выделении: браузеры не разрешают веб-расширению без постоянного пользовательского разрешения произвольно дописывать данные в файл на диске.

Хранится не более 5000 последних записей. Список можно очистить из popup-окна.

## Используемые возможности

- Web Speech API — озвучка наиболее естественным доступным голосом нужного языка;
- MyMemory API — контекстный перевод с английского на русский: выделенное слово переводится внутри предложения, варианты очищаются от нерелевантных данных, изменённые формы дополнительно ищутся по базовой форме;
- Datamuse API — основная IPA-транскрипция английских слов и фраз (до 30 слов); ответы ARPAbet автоматически преобразуются в IPA;
- Free Dictionary API — резервный источник IPA-транскрипции;
- English Wiktionary — словарные варианты перевода по частям речи; порядок вариантов уточняется по контексту;
- стандартные API `runtime` и `storage` с `async/await`, совместимые с Chrome/Edge (MV3) и Firefox (MV2).

Для перевода и словарной транскрипции требуется интернет. На системных страницах вида `chrome://…` content script не запускается — это ограничение браузера.

Словарные данные English Wiktionary доступны по лицензиям проекта Wikimedia; источник: https://en.wiktionary.org/.
