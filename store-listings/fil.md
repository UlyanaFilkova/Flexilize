PAGLALARAWAN

Awtomatikong natutukoy ng extension ang wika ng tekstong pinili sa isang webpage. Ipinapakita nito ang salin, gabay sa pagbigkas, salin ayon sa konteksto ng buong pangungusap o talata, at pinatutunog ang orihinal na teksto. Buksan agad ang tagasalin gamit ang keyboard shortcut.

PARA SAAN ITO?

1) Isalin agad ang mga salitang hindi pamilyar o buong pangungusap. Piliin ang teksto para makita ang salin nang hindi ito kinokopya, nagbubukas ng bagong tab, o naghahanap ng diksyunaryo.

2) Isalin ang sarili mong teksto nang hindi umaalis sa kasalukuyang tab. Buksan ang window ng tagasalin gamit ang keyboard shortcut, saka mag-type o mag-paste ng teksto.

3) Matuto ng wika ayon sa konteksto. Suriin ang mga salitang hindi pamilyar habang nagbabasa at i-save ang mga ito kasama ang konteksto.

4) Bumuo ng sarili mong talasalitaan. Awtomatikong i-save ang mahahalagang detalye at i-export ang mga ito sa isang file.

MGA TAMPOK NG EXTENSION

MGA FUNCTION:

- Awtomatikong tinutukoy ang wika ng piniling teksto.
- Isinasalin ang piniling salita, parirala, pangungusap, o talata sa wikang pinili mo.
- Nagbubukas ng hiwalay na window ng tagasalin para maglagay ng teksto.
- Isinasalin ayon sa konteksto ang pangungusap o talatang nakapaligid sa piniling teksto.
- Ipinapakita ang gabay sa pagbigkas at iba pang posibleng salin.
- Binibigkas ang orihinal na teksto.
- Awtomatiko o mano-manong sine-save ang salin kasama ang konteksto, gabay sa pagbigkas, URL at pamagat ng pahina.
- Nagpapakita ng kasaysayan ng hanggang 5,000 salin.
- Nagbibigay-daan na i-edit, burahin at ibalik ang mga tala, o burahin ang buong kasaysayan.
- Ini-export ang buong kasaysayan.
- Lokal na sine-save ang kasaysayan at mga setting sa iyong device.

MGA NAIANGKOP NA SETTING

- Manu-manong piliin ang wika ng pinagmulan at target na wika.
- Itakda na magsimula lamang ang pagsasalin ng piniling teksto kapag ginamit ang keyboard shortcut.
- I-customize ang mga keyboard shortcut.
- I-on o i-off ang gabay sa pagbigkas at pagbigkas ng teksto.
- Ayusin ang bilis ng pagbigkas mula 0.3× hanggang 2×.
- I-on ang awtomatikong pag-save o i-save ang mga salin gamit ang button.
- Piliin kung iikot ang kasaysayan. Kapag naabot ang limitasyon, awtomatikong papalitan ang mga pinakalumang tala. Kung naka-off ang pag-ikot, hindi mase-save ang mga bagong tala hangga't walang nababakanteng espasyo.

PARA KANINO ANG CONTEXT TRANSLATOR?

Kapaki-pakinabang ang extension kung:

- nagbabasa ka ng mga artikulo, balita, o dokumentasyon sa ibang wika;
- nag-aaral ka ng mga bagong salita sa natural na konteksto ng mga ito;
- gusto mong alamin ang kahulugan ng parirala nang hindi umaalis sa pahina;
- gumagawa ka ng sarili mong talasalitaan o mga card para sa pag-uulit;
- nagtatrabaho ka sa nilalamang maraming wika.

PRIBADONG IMPORMASYON AT PAG-IIMBAK NG DATA

Lokal na iniimbak sa browser ang kasaysayan ng pagsasalin at mga setting. Para magsalin at kumuha ng gabay sa pagbigkas, maaaring ipadala ang piniling teksto sa mga serbisyo ng pagsasalin at sangguniang diksyunaryo na ginagamit ng extension. Kailangan ng koneksiyon sa Internet ang mga feature na ito.

Hindi ipinagbibili ng extension ang data ng mga gumagamit at hindi ito ginagamit para sa advertising, pagtatasa ng kredito, o mga layuning walang kaugnayan sa pangunahing mga function nito. Maaari mong burahin ang mga indibidwal na tala o ang buong kasaysayan sa extension. Para tuluyang alisin ang kasaysayan, mga setting, at lokal na cache, i-uninstall ang extension o burahin ang data nito sa browser.

Pinapasimple ng Context Translator ang proseso: piliin ang teksto, unawain agad ang kahulugan nito, at i-save ang salin para sa pag-aaral sa hinaharap kung kailangan.
