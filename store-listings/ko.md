설명

확장 프로그램은 웹페이지에서 선택한 텍스트의 언어를 자동으로 감지하고 번역, 발음 표기, 문장이나 단락 전체의 문맥 번역을 보여 주며 원문을 음성으로 재생합니다. 단축키를 누르면 번역기를 바로 열 수 있습니다.

어떤 기능인가요?

1) 낯선 단어나 문장 전체를 바로 번역합니다. 텍스트를 선택하면 복사하거나 새 탭에서 번역기와 사전을 찾을 필요 없이 번역을 확인할 수 있습니다.

2) 현재 탭을 벗어나지 않고 직접 작성한 텍스트를 번역합니다. 단축키로 번역기 창을 열고 텍스트를 입력하거나 붙여 넣으세요.

3) 문맥 속에서 언어를 학습합니다. 읽는 중에 모르는 단어를 확인하고 주변 문장과 함께 저장할 수 있습니다.

4) 나만의 어휘 목록을 만듭니다. 필요한 정보를 자동으로 저장하고 파일로 내보내세요.

확장 프로그램 기능

기능:

- 선택한 텍스트의 언어를 자동으로 감지합니다.
- 선택한 단어, 구절, 문장 또는 단락을 원하는 언어로 번역합니다.
- 텍스트 입력을 위한 별도의 번역기 창을 엽니다.
- 선택한 텍스트 주변의 문장이나 단락을 문맥에 맞게 번역합니다.
- 발음 표기와 다른 번역을 보여 줍니다.
- 원문을 음성으로 재생합니다.
- 문맥, 발음 표기, 페이지 URL과 제목을 포함해 번역을 자동 또는 수동으로 저장합니다.
- 최대 5,000개의 번역 기록을 확인할 수 있습니다.
- 기록을 수정, 삭제, 복원하거나 전체 기록을 지울 수 있습니다.
- 전체 기록을 내보냅니다.
- 기록과 설정을 기기에 로컬로 저장합니다.

유연한 설정

- 원본 언어와 번역 언어를 직접 선택합니다.
- 단축키를 눌렀을 때만 선택 텍스트를 번역하도록 설정합니다.
- 단축키를 변경합니다.
- 발음 표기와 음성 재생을 켜거나 끕니다.
- 음성 재생 속도를 0.3×에서 2×까지 조절합니다.
- 자동 저장을 켜거나 버튼을 눌러 저장합니다.
- 기록 순환 여부를 선택합니다. 한도에 도달하면 오래된 기록이 자동으로 교체됩니다. 순환을 끄면 공간을 확보할 때까지 새 기록이 저장되지 않습니다.

Context Translator는 누구에게 유용한가요?

다음과 같은 경우에 유용합니다.

- 외국어 기사, 뉴스 또는 문서를 읽는 경우
- 문맥 속에서 새 단어를 익히는 경우
- 페이지를 떠나지 않고 표현의 뜻을 확인하고 싶은 경우
- 개인 어휘 목록이나 복습용 카드를 만드는 경우
- 여러 언어로 된 콘텐츠를 다루는 경우

개인정보 보호 및 데이터 저장

번역 기록과 설정은 브라우저에 로컬로 저장됩니다. 번역과 발음 표기를 제공하기 위해 선택한 텍스트가 확장 프로그램에서 사용하는 번역 서비스와 사전 출처로 전송될 수 있습니다. 이 기능을 사용하려면 인터넷 연결이 필요합니다.

확장 프로그램은 사용자 데이터를 판매하지 않으며 광고, 신용 평가 또는 주요 기능과 무관한 목적으로 사용하지 않습니다. 확장 프로그램에서 개별 기록을 삭제하거나 전체 기록을 지울 수 있습니다. 기록, 설정 및 로컬 캐시를 완전히 삭제하려면 확장 프로그램을 제거하거나 브라우저에서 데이터를 삭제하세요.

Context Translator는 간단한 흐름을 제공합니다. 텍스트를 선택해 바로 뜻을 이해하고, 필요하면 나중에 학습할 수 있도록 번역을 저장하세요.
